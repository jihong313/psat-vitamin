## 2. 📅 다른 기기에 캘린더 동기화하는 방법 (.ics)

스마트폰(iPhone, Galaxy)과 태블릿(iPad)에서 일정을 확인하고 **10분 전 알림(`VALARM`)**을 받으려면, **구글 캘린더** 또는 **애플 캘린더**에 3개 파일([psat_study.ics](file:///c:/Users/Administ/Desktop/psat/plan/psat_study.ics), [college_classes.ics](file:///c:/Users/Administ/Desktop/psat/plan/college_classes.ics), [daily_routine.ics](file:///c:/Users/Administ/Desktop/psat/plan/daily_routine.ics))을 등록하세요.

### 방법 A. 구글 캘린더 연동 (가장 추천: 전 기기 자동 실시간 동기화)
1. PC 웹 브라우저에서 [Google 캘린더](https://calendar.google.com)에 로그인합니다.
2. 좌측 메뉴 **'다른 캘린더'** 옆 **`+`** 아이콘 클릭 ➔ **'새 캘린더 만들기'**를 선택합니다.
3. 다음 이름으로 캘린더 3개를 각각 만듭니다:
   * 🟦 `PSAT 공부`
   * 🟩 `대학 수업 및 시험`
   * 🟨 `생활 루틴`
4. 좌측 메뉴 상단의 **설정(톱니바퀴)** ➔ **'가져오기 및 내보내기'**로 이동합니다.
5. `plan/` 폴더 내의 `.ics` 파일을 각각 해당 캘린더로 가져옵니다:
   * `psat_study.ics` ➔ `PSAT 공부` 캘린더로 가져오기
   * `college_classes.ics` ➔ `대학 수업 및 시험` 캘린더로 가져오기
   * `daily_routine.ics` ➔ `생활 루틴` 캘린더로 가져오기
6. **동기화 완료**: 이제 스마트폰(아이폰/갤럭시)이나 아이패드의 기본 캘린더 앱 또는 Google Calendar 앱을 열면 모든 일정이 실시간으로 나타납니다. 언제든 필요한 캘린더만 체크 해제하여 숨길 수 있습니다.

### 방법 B. 애플 기기 (iPhone / iPad / Mac) 직접 등록
* Mac이나 iPhone/iPad로 `.ics` 파일을 AirDrop 또는 카카오톡/이메일로 보낸 뒤 파일을 터치하면 바로 새로운 캘린더로 추가할 수 있습니다.

## 3. ⚡ 'PSAT Vitamin Lab'을 스마트폰/아이패드에서 사용하는 방법

PC 브라우저뿐만 아니라 **침대나 독서실에서 스마트폰이나 태블릿(터치/블루투스 키보드)**으로 연산 연습을 진행할 수 있습니다.

### 방법 A. 집/카페 같은 Wi-Fi에서 바로 접속하기 (가장 간단)
PC와 모바일 기기가 같은 공유기(Wi-Fi)에 연결되어 있을 때 사용합니다.

1. **PC에서 로컬 서버 실행**:
   이 폴더에서 터미널(PowerShell 또는 CMD)을 열고 아래 명령어를 입력합니다.
   ```powershell
   python -m http.server 8080
   ```
2. **PC의 내부 IP 확인**:
   ```powershell
   ipconfig
   ```
   * `IPv4 주소` 확인 (예: `192.168.0.15`)
3. **스마트폰/태블릿 브라우저로 접속**:
   * 모바일 사파리나 크롬 주소창에 `http://192.168.0.15:8080` 입력!
4. **💡 홈 화면에 추가 (앱처럼 사용하기)**:
   * **아이폰/아이패드 (Safari)**: 하단 공유 버튼 ➔ `홈 화면에 추가`
   * **갤럭시/안드로이드 (Chrome)**: 우측 상단 메뉴 ➔ `홈 화면에 추가`
   * 앱 아이콘이 생성되어 전체 화면 모드로 깔끔하게 연산 연습이 가능합니다.

### 방법 B. GitHub Pages로 무료 웹 배포 (언제 어디서나 접속)
밖에서도 인터넷만 되면 링크 하나로 접속하고 싶을 때:
1. GitHub에 새 저장소(Public Repository, 예: `psat-vitamin`)를 만듭니다.
2. 본 폴더의 파일들을 업로드합니다.
3. 저장소의 **Settings** ➔ **Pages** ➔ Branch를 `main`, Folder를 `/ (root)`로 지정하고 Save합니다.
4. 발급된 URL(`https://<사용자아이디>.github.io/psat-vitamin/`)을 통해 언제 어디서든 모바일로 접속할 수 있습니다.

## 5. 🎯 PSAT Vitamin Lab 핵심 기능 요약

* **6가지 핵심 훈련 모드**:
  1. **➕ 덧셈**: 2자리+2자리, 4자리+4자리, 2자리 연속 합산(3~4개)
  2. **➖ 뺄셈**: 2자리-2자리, 4자리-4자리, 990보수법, 징검다리법
  3. **✖️ 곱셈**: 2×2, 자릿수×1자리, 합10 특수곱셈, 11단 비법, 10대·20대 곱셈
  4. **⚖️ 분수 비교**: A/B vs C/D 증가율 비교 및 초미세(1~3%) 차분법 판정
  5. **🔄 곱셈 비교**: 자료해석 선지형 A×B vs C×D 상쇄 대소 비교
  6. **💊 종합 비타민**: 전 영역 무작위 출제 실전 스피드런
* **유형별 세부 커스텀**:
  * 복수 유형 다중 선택(Multi-select)
  * 문항 수 균등 자동 분배 vs 유형별 문항 수 직접 지정(Custom Stepper)
  * 난이도 3단계 (기초 Level 1 / 실전 Level 2 / 고난도 Level 3)
* **스마트 학습 관리**:
  * **오늘 순 공부 시간 자동 트래킹** (탭 비활성화 시 자동 정지)
  * **사운드 피드백** (Web Audio API 신시사이저 기반 무지연 효과음)
  * **오답노트 보관함(Vault)**: 틀린 문제 자동 수집 및 복습
  * **회차별 기록실(Session History)**: 최근 50회차 속도/정답률 변화 추적
* **키보드 단축키**:
  * `숫자패드 Enter` / `Space`: 시작 및 다음 문제
  * `←` / `A`, `→` / `B`: 분수·곱셈 대소 비교 판정
  * `M`: 효과음 음소거 토글, `Esc`: 모달 닫기
